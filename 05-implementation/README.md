# Phase 05: Implementation

**Standard**: ISO/IEC/IEEE 12207:2017 (Implementation Process)

## Purpose

Write clean, tested code following TDD (Red-Green-Refactor). **Critical Rule**: Write new code ONLY if an automated test has failed.

## Deliverables

- Source code with test coverage >80%
- Implementation documentation
- Code review evidence
- Continuous integration results

## Exit Criteria

- [ ] All tests pass
- [ ] Coverage threshold met
- [ ] No vendor/OS-specific code in standards layer
- [ ] Code reviewed and approved
- [ ] CI green

## Directory Structure

```
05-implementation/
├── src/       # Implementation notes and evidence
├── tests/     # Test documentation
└── docs/      # Implementation decisions
```
